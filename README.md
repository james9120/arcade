# Arcade

A pile of tiny HTML games we can play in a phone browser.

**Play:** https://james9120.github.io/arcade/

Each game lives in `games/<name>/` with its own `index.html`. The homepage lists them.

- [Slash Pit](https://james9120.github.io/arcade/games/slash-pit/) — 2.5D hack-and-slash crawler. Fast loot, no crafting.
