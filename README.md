# Arcade

A pile of tiny HTML games we can play in a phone browser.

**Play:** https://james9120.github.io/arcade/

Each game lives in `games/<name>/` with its own `index.html`. The homepage lists them. Pallet Town is the exception: its source is `pallet-3d-src/`, and the Pages workflow builds it into `/pallet-3d/`.

- [Slash Pit](https://james9120.github.io/arcade/games/slash-pit/) — 2.5D hack-and-slash crawler. Fast loot, no crafting.
- [Pallet Town](https://james9120.github.io/arcade/pallet-3d/) — 3D walk from Pallet Town into Route 1. A FireRed US v1.0 ROM is required and stays in the browser; the site ships no Nintendo assets.
